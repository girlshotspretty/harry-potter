# Página Informativa: O Mundo Mágico de Harry Potter

## Descrição do Projeto
Este projeto é uma página web informativa em formato de artigo digital focada na franquia Harry Potter. O site aborda a história da obra, a divisão das quatro casas de Hogwarts e a ordem cronológica dos livros, aplicando práticas de HTML semântico, acessibilidade, estilização com CSS responsivo e versionamento open-source.

## Tema Escolhido
* Cultura Pop & Literatura: O Universo de Harry Potter.

## Tecnologias Utilizadas
* **HTML5:** Estruturação semântica com `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>` e `<footer>`.
* **CSS3:** Design responsivo, paleta temática e layouts dinâmicos com CSS Grid e Flexbox.
* **Git & GitHub:** Versionamento do código e controle de branches.
* **GitHub Pages:** Hospedagem gratuita da aplicação.
